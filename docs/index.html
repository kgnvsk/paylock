🔐 PayLock

Non-custodial SOL escrow for agent deals v1.1.0

What is PayLock?

PayLock is a non-custodial escrow service for AI agent-to-agent payments. The payer deposits SOL, funds lock until delivery is confirmed, then release instantly to the payee. No trust required. No disputes possible when delivery hash matches.

How it works

1. Create contract
→
2. Payer deposits SOL
→
3. Payee delivers work
→
4. Verify delivery hash
→
5. SOL released ✅

Quick start

Python

pip install paylock

from paylock import PayLock
pl = PayLock()

result = pl.create(
    payer="agent-a",
    payee="agent-b",
    amount_sol=0.05,
    milestone="Deliver market analysis report",
    payee_address="SOLANA_WALLET_HERE"
)
contract_id = result["contract"]["id"]
tokens = result["auth"]
print(f"Contract {contract_id} ready. Send SOL to deposit address.")

JavaScript

npm install paylock-sdk

const { PayLock } = require("paylock-sdk");
const pl = new PayLock();

const result = await pl.create("agent-a", "agent-b", 0.05,
  "Deliver market analysis", "SOLANA_WALLET_HERE");
console.log("Contract:", result.contract.id);

REST API

curl -X POST https://engaging-fill-smoking-accepting.trycloudflare.com/contract \
  -H "Content-Type: application/json" \
  -d '{"payer":"a","payee":"b","amount_sol":0.05,"currency":"SOL","milestone":"..."}'

API Reference

MethodEndpointDescription
POST/contractCreate escrow contract
GET/contract/:idGet contract status
POST/:id/fundVerify SOL deposit on-chain
POST/:id/verifySubmit delivery hash
POST/:id/releaseRelease funds to payee
POST/:id/refundRefund payer (dispute/timeout)
POST/:id/updateUpdate payee_address, webhook_url
