What is MCP?

Model Context Protocol (MCP) is an open standard that allows AI models to call external tools. Instead of copy-pasting wallet addresses and manually filling forms, your AI agent manages the complete escrow lifecycle through structured tool calls.

PayLock is the first SOL-native escrow with full MCP support — enabling trustless agent-to-agent payments at the protocol level.

Quick Start

  1. Add to claude_desktop_config.json

    Open your Claude Desktop config and add the PayLock MCP server.

  2. Restart Claude Desktop

    The PayLock tools will appear in Claude's tool list automatically.

  3. Create your first contract

    Ask Claude: "Create a PayLock escrow for 0.5 SOL for building an API"

claude_desktop_config.json

{
  "mcpServers": {
    "paylock": {
      "url": "https://paylock.xyz/mcp"
    }
  }
}

Config file location: ~/Library/Application Support/Claude/claude_desktop_config.json (macOS)

Code Examples

Create an escrow contract

# Claude can now do this in one tool call:
create_contract(
  amount=0.5,
  description="Build REST API with auth",
  payer_wallet="PAYER_SOL_ADDRESS",
  payee_wallet="PAYEE_SOL_ADDRESS",
  expires_hours=72
)
# Returns: contract_id, deposit_address, expires_at

Full lifecycle in one conversation

# 1. Create contract
contract = create_contract(amount=1.0, description="Smart contract audit", ...)

# 2. Payer funds → sends SOL to contract.deposit_address

# 3. Verify delivery after work is done
verify_delivery(contract_id=contract.id, delivery_hash="sha256:...")

# 4. Release funds to payee
release_funds(contract_id=contract.id)

# 5. Or open a dispute if something's wrong
open_dispute(contract_id=contract.id, reason="Delivery incomplete")
💚 3% fee on release. Non-custodial — funds go directly to a contract-specific deposit address. No middlemen holding your SOL.

How It Works

Non-custodial

Each contract generates a unique deposit address. Funds are locked on-chain, not held by PayLock.

Delivery Verification

Submit a SHA-256 hash of your deliverable. PayLock verifies it matches before releasing funds.

Dispute Resolution

Either party can open a dispute. Admin reviews and decides within 48 hours.

SOL Native

Built on Solana for fast, cheap transactions. 3% fee only charged on successful release.
