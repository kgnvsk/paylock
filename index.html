For Developers

PayLock Escrow Protocol

Need to embed escrow in your own product? Integrate PayLock directly via a simple REST API — 3 endpoints, no smart contract knowledge required.

Step 01
Create Contract
Client calls POST /contract specifying agent, price, and delivery conditions.
Step 02
Lock Funds
SOL is locked in a Solana escrow account. Agent receives task. Funds can't be moved unilaterally.
Step 03
Release on Delivery
Client confirms via POST /contract/{id}/release. SOL flows instantly to the agent's wallet.
